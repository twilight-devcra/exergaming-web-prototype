# 미니게임 난이도 설명서

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

모든 미니게임은 Lv1~8 의 난이도가 있고, 레벨마다 몇 가지 **손잡이**(난이도를 정하는 값)를 다르게 둡니다.
게임마다 손잡이의 뜻과 레벨별 값, 문제 수, 제한 시간, 능력 그래프에 들어가는 몫을 적었습니다.

## 공통

- **레벨**: Lv1·Lv2 는 쉬운 단계(어르신용으로 나중에 더함), **Lv3** 가 기본 시작 레벨입니다. 쉬운 단계는 문제 제한 시간을 Lv1 ×2, Lv2 ×1.6 로 늘립니다.
- **제한 시간** = (base + per × 일의 양) 초 × 쉬운 단계 배율 × 라운드 난이도의 `questionTimeScale`. 입력을 받기 시작한 때부터 게임 시계로 잽니다. 게임마다 base·per 와 '일의 양' 이 무엇인지 게임 쪽에 적었습니다 (`js/config.js` 의 `questionTime`).
- **점수 배율** (기본 설정): Lv1 ×1.00 · Lv2 ×1.26 · Lv3 ×1.58 · Lv4 ×1.99 · Lv5 ×2.51 · Lv6 ×3.16 · Lv7 ×3.97 · Lv8 ×5.00
- **난이도 계기판** (기본 `adaptive`): 모든 게임이 같이 씁니다. 정답마다 +0.4, 오답·시간 초과마다 −0.6, 다음 게임 레벨은 계기판의 정수 부분입니다. 켠 게임이 2종보다 많으면 두 값을 2 / 게임 수 로 줄입니다. 운영 버전은 세션 길이·난이도로 이 값을 따로 정합니다 (`Config.session`).
- **능력 그래프**: 게임마다 능력 축(기억력 · 공간지각 · 주의집중 · 논리·수리 · 처리속도)에 몫을 나눠 줍니다. 처리속도 몫이 있는 게임 가운데 몇은 문제당 걸린 시간으로 그 몫을 깎습니다 (느리면 최대 ×0.6).
- 레벨 표에서 `–` 는 그 레벨에 값을 두지 않았다는 뜻입니다 (손잡이 설명에 적힌 기본값이나 꺼짐). `a~b` 는 그 범위에서 무작위로 고른다는 뜻입니다.
