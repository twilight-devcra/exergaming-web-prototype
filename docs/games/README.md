# 미니게임 난이도 문서

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

모든 미니게임은 Lv1~8의 난이도가 있으며, 레벨마다 몇 가지 **난이도 변수** 값이 달라집니다.
게임별로 난이도 변수의 의미와 레벨별 값, 문제 수, 제한 시간, 능력 그래프 가중치를 정리했습니다.

## 공통 규칙

- **레벨**: Lv1·Lv2는 고령자용으로 추가한 쉬운 단계이고, 기본 시작 레벨은 **Lv3**입니다. 쉬운 단계에서는 문제 제한 시간이 늘어납니다 (Lv1 ×2, Lv2 ×1.6).
- **제한 시간** = (기본 시간 + 단위 시간 × N)초 × 쉬운 단계 배율 × 라운드 난이도의 `questionTimeScale`. N은 게임마다 정한 문제 크기(빈칸 수, 조각 수 등)이며, 게임별 문서에 적었습니다. 입력을 받기 시작한 시점부터 게임 시계 기준으로 잽니다 (`js/config.js`의 `questionTime`).
- **점수 배율** (기본 설정): Lv1 ×1.00 · Lv2 ×1.26 · Lv3 ×1.58 · Lv4 ×1.99 · Lv5 ×2.51 · Lv6 ×3.16 · Lv7 ×3.97 · Lv8 ×5.00
- **난이도 자동 조절** (기본 `adaptive`): 모든 게임이 하나의 난이도 값을 공유합니다. 정답이면 +0.4, 오답·시간 초과면 −0.6이고, 다음 게임의 레벨은 이 값의 정수 부분입니다. 활성화된 게임이 2종보다 많으면 두 증감 폭에 (2 / 게임 수)를 곱합니다. 운영 버전에서는 세션 길이와 난이도 설정에 따라 이 값을 따로 정합니다 (`Config.session`).
- **두뇌 그래프** (결과 화면): 인지 영역(기억력 · 시공간 · 계산 · 전두엽 · 주의집중 · 언어)마다 그 영역을 쓰는 게임들의 정답률을 보여 줍니다. 게임마다 주 영역은 1, 부분 영역은 0.5 의 비중으로 셉니다. 영역 축 뒤에 답하는 속도(문제마다 제한 시간 가운데 남긴 몫)와 운동(목표 속도를 지킨 비율) 축이 붙습니다.
- 레벨 표의 `–`는 해당 레벨에서 값을 지정하지 않았다는 뜻입니다 (변수 설명의 기본값을 쓰거나 기능이 꺼짐). `a~b`는 그 범위에서 무작위로 정한다는 뜻입니다.
