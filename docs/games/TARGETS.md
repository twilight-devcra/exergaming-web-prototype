# 인지 영역 점검표

> 이 문서는 `node tools/manual.js`가 `tools/targets.js`와 게임 목록에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 게임을 추가하면 `tools/targets.js`의 `GAME_TARGETS`에 그 게임이 다루는 세부 영역을 적은 뒤 스크립트를 다시 실행하세요.

새 미니게임을 기획할 때, 기존 게임이 아직 다루지 않는 인지 영역을 찾기 위한 표입니다.
DSM-5의 신경인지 영역과 세부 영역을 바탕으로 계산, 일상생활 과제, 이중 과제를 추가했습니다. 결과 화면의 능력 그래프(5개 축)와는 별개입니다.

**☑** 주 영역으로 다루는 게임 2종 이상 · **△** 1종뿐이거나 부분적으로만 다룸 · **☐** 없음 · *계획*: [NEW_GAMES_BRIEF.md](../NEW_GAMES_BRIEF.md)에만 있는 게임

## 복합 주의 (Complex attention)

- ☑ <a id="selective"></a>**선택적 주의** — 방해 자극 속에서 목표만 골라 보는 능력. 대표 검사: 시각 탐색 과제, 지우기 검사
  - 주 영역: [우세한 색 찾기](count.md), [숨은 순서 찾기](seek.md), [짝 없는 것 찾기](pair.md), [동전 세기](coin.md)
- ☑ <a id="tracking"></a>**지속적 주의 · 시각 추적** — 움직이거나 이어지는 대상을 놓치지 않고 계속 따라가는 능력. 대표 검사: CPT(연속 수행 검사), 다중 대상 추적(MOT)
  - 주 영역: [배관 타기](pipe.md), [공 따라가기](track.md)
- △ <a id="divided"></a>**분할 주의 · 이중 과제** — 두 가지 일을 동시에 처리하는 능력. 대표 검사: 이중 과제 보행 검사
  - 부분: [공 따라가기](track.md)
  - 게임 아이디어 (우선순위 높음): 페달과 게임을 연동한다. 예: 빨간 신호가 나오면 페달을 빠르게 밟기처럼 응답 하나를 페달로 받는다. 이중 과제 수행 능력은 노인 낙상 위험과 관련이 깊어 연구가 많다.
- ☑ <a id="speed"></a>**처리 속도** — 보고 판단하는 속도. 대표 검사: 기호 바꾸기 검사(WAIS 기호 쓰기, SDMT)
  - 주 영역: [우세한 색 찾기](count.md), [숨은 순서 찾기](seek.md), [배관 타기](pipe.md), [짝 없는 것 찾기](pair.md), [두 그림 비교하기](compare.md)
  - 참고: 현재는 다른 게임의 문제당 소요 시간으로만 측정한다. 속도 자체를 목표로 하는 게임(예: 그림-숫자 짝 바꾸기)은 없다.

## 실행 기능 (Executive function)

- ☑ <a id="wm"></a>**작업 기억** — 머릿속에 정보를 유지하면서 갱신하거나 계산하는 능력. 대표 검사: 숫자 거꾸로 따라 하기, n-back
  - 주 영역: [가린 숫자 더하기](cover.md), [지시 따르기](follow.md), [상자 속 과일 세기](box.md)
  - 부분: [사칙연산 역산](arith.md), [같은 글자 넣기](blank.md)
- △ <a id="inhibition"></a>**억제** — 자동으로 나오는 반응을 참는 능력. 대표 검사: Stroop 검사, go/no-go
  - 부분: [지시 따르기](follow.md)
  - 게임 아이디어 (우선순위 높음): go/no-go: 그림이 나올 때마다 누르되 특정 그림 하나만은 누르지 않기. 또는 Stroop 변형: 글자 뜻이 아니라 글자 색 고르기 (색각 이상을 고려해 모양도 함께 쓴다).
- ☐ <a id="flexibility"></a>**인지적 유연성 · 전환** — 규칙을 바꿔 가며 적용하는 능력. 대표 검사: 선로 잇기 검사 B형(1-가-2-나…), 위스콘신 카드 분류 검사
  - 게임 아이디어 (우선순위 높음): 선로 잇기 B형처럼 숫자와 글자를 번갈아 순서대로 누르기. 또는 위 칸에 나오면 모양으로, 아래 칸에 나오면 개수로 분류하기.
- △ <a id="planning"></a>**계획** — 몇 단계 앞을 내다보고 순서를 정하는 능력. 대표 검사: 런던 탑 검사
  - 주 영역: [조각 잇기](chain.md)
  - 게임 아이디어 (우선순위 중간): 최소 횟수로 원판 옮기기, 여러 가게를 가장 짧은 경로로 도는 순서 정하기.
- △ <a id="reasoning"></a>**추론 · 규칙 찾기** — 주어진 예에서 규칙을 찾아 다음을 예측하는 능력. 대표 검사: 행렬 추론, 수열 완성
  - 부분: [사칙연산 역산](arith.md), [지시 따르기](follow.md)
  - 게임 아이디어 (우선순위 높음): "다음에 올 그림은?": 모양·개수·방향이 한 가지 규칙에 따라 바뀌는 줄에서 다음 칸 고르기.

## 계산 (Numeracy · SNSB 계산, CHC Gq)

- ☑ <a id="calc"></a>**계산 · 수 감각** — 수를 세고 더하고 빼는 능력. 대표 검사: MMSE 100-7, SNSB 계산
  - 주 영역: [사칙연산 역산](arith.md), [가린 숫자 더하기](cover.md), [상자 속 과일 세기](box.md), [동전 세기](coin.md)

## 학습 및 기억 (Learning & memory)

- ☑ <a id="stm"></a>**즉시 기억 (시각·위치)** — 방금 본 것을 바로 떠올리는 능력. 대표 검사: 공간 폭 검사, 그림 재인
  - 주 영역: [길 따라 그리기](path.md), [심볼 위치 외우기](symbol.md), [가린 숫자 더하기](cover.md), [없던 그림 찾기](novel.md)
  - 부분: [상자 속 과일 세기](box.md)
  - 계획: [장보기](../NEW_GAMES_BRIEF.md) (`shop`)
- ☑ <a id="sequence"></a>**순서 기억** — 본 순서대로 떠올리는 능력. 대표 검사: 숫자 따라 하기, 코르시 블록
  - 주 영역: [길 따라 그리기](path.md), [차례대로 외우기](recall.md)
  - 부분: [지시 따르기](follow.md)
- △ <a id="verbal"></a>**언어적 기억** — 이름을 붙여 되뇌며 외우는 능력. 대표 검사: CERAD 단어 목록 기억
  - 주 영역: [차례대로 외우기](recall.md)
  - 계획: [장보기](../NEW_GAMES_BRIEF.md) (`shop`)
- △ <a id="assoc"></a>**연합 기억** — 두 정보를 짝지어 기억하는 능력 (얼굴-이름, 물건-위치). 대표 검사: 얼굴-이름 연합 검사, 물건-위치 기억
  - 부분: [심볼 위치 외우기](symbol.md)
  - 게임 아이디어 (우선순위 중간): 물건과 놓인 위치, 사람 그림과 이름을 짝지어 보여 준 뒤 한쪽을 주고 짝 고르기.
- ☐ <a id="delayed"></a>**지연 회상** — 몇 분이 지난 뒤 다시 떠올리는 능력. 대표 검사: CERAD·MMSE 지연 회상
  - 게임 아이디어 (우선순위 높음): 세션 초반에 그림 3개를 보여 주고 세션 끝에 묻기. 치매 초기에 가장 먼저 저하되는 능력이고, 세션이 몇 분 단위라 구조에도 잘 맞는다.
- ☐ <a id="prospective"></a>**미래 기억** — 해야 할 일을 적절한 때에 떠올리는 능력. 대표 검사: 미래 기억 과제 ("이 그림이 나오면 …")
  - 게임 아이디어 (우선순위 중간): 세션 초반에 "별이 보이면 ★ 버튼을 누르세요"라고 알려 주고, 다른 게임 도중에 별을 띄우기.

## 언어 (Language)

- △ <a id="comprehension"></a>**언어 이해** — 읽거나 들은 말을 이해하고 따르는 능력. 대표 검사: 토큰 검사, 지시 따르기
  - 주 영역: [지시 따르기](follow.md)
- △ <a id="fluency"></a>**낱말 인출 · 유창성** — 단서(첫 글자 등)에 맞는 낱말을 머릿속에서 찾아 꺼내는 능력. 대표 검사: 음소 유창성 검사(COWAT: ㄱ으로 시작하는 낱말 말하기)
  - 주 영역: [같은 글자 넣기](blank.md)
  - 게임 아이디어 (우선순위 중간): 빈칸 낱말 여러 개에 공통으로 들어갈 글자 고르기. 말하기 대신 보기에서 고른다.
- △ <a id="naming"></a>**이름 대기** — 그림을 보고 이름을 떠올리는 능력. 대표 검사: 보스턴 이름 대기 검사(K-BNT)
  - 부분: [같은 글자 넣기](blank.md)
  - 게임 아이디어 (우선순위 중간): 그림 하나를 보여 주고 낱말 3개 중 맞는 이름 고르기, 또는 초성을 보고 맞는 그림 고르기. 음성 입력이 없으므로 보기에서 고르는 방식으로 한다.
- ☐ <a id="semantic"></a>**의미 기억 · 범주화** — 낱말과 사물의 뜻을 알고 같은 범주끼리 묶는 능력. 대표 검사: 범주 유창성 검사, 의미 연합 검사
  - 게임 아이디어 (우선순위 중간): 과일·채소·옷 등으로 분류하기, 4개 중 범주가 다른 하나 고르기.

## 지각-운동 기능 (Perceptual-motor)

- ☑ <a id="discrim"></a>**시각 변별** — 비슷한 모양의 작은 차이를 알아보는 능력. 대표 검사: 시각 변별 검사
  - 주 영역: [짝 없는 것 찾기](pair.md), [두 그림 비교하기](compare.md)
- △ <a id="rotation"></a>**심상 회전** — 모양을 머릿속에서 돌려 보는 능력. 대표 검사: 심상 회전 과제(Shepard-Metzler)
  - 주 영역: [빈자리 채우기](fit.md)
  - 게임 아이디어 (우선순위 중간): 회전한 그림 중 같은 것 고르기, 거울상과 회전한 것 구별하기.
- △ <a id="construct"></a>**시각 구성** — 부분을 조합해 전체 모양을 만드는 능력. 대표 검사: 토막 짜기, 시계 그리기 검사
  - 주 영역: [빈자리 채우기](fit.md)
  - 게임 아이디어 (우선순위 중간): 두 조각을 합치면 되는 모양 고르기, 칠교 그림에서 빠진 조각 고르기.
- ☐ <a id="orientation"></a>**공간 지남력 · 길찾기** — 자기 기준의 왼쪽·오른쪽을 구분하고 지도를 읽는 능력. 대표 검사: 길찾기 과제, 지남력 검사
  - 계획: [집 찾아가기](../NEW_GAMES_BRIEF.md) (`map`)

## 사회 인지 (Social cognition)

- ☐ <a id="emotion"></a>**정서 인식** — 얼굴 표정에서 감정을 읽는 능력. 대표 검사: 표정 인식 검사
  - 게임 아이디어 (우선순위 낮음): 표정 그림 4개 중 "기뻐하는 사람" 고르기. 그림 자원이 많이 필요해 우선순위를 낮춘다.

## 일상생활 기능 (Everyday function · IADL)

- △ <a id="iadl"></a>**도구적 일상생활 과제** — 돈 계산, 장보기, 시계·달력 보기처럼 일상에서 하는 인지 과제. 대표 검사: K-IADL
  - 주 영역: [동전 세기](coin.md)
  - 계획: [장보기](../NEW_GAMES_BRIEF.md) (`shop`), [집 찾아가기](../NEW_GAMES_BRIEF.md) (`map`)
  - 게임 아이디어 (우선순위 중간): 시곗바늘을 보고 시각 고르기, 달력에서 "다음 주 화요일" 찾기, 약 봉투의 복용 시간 맞추기.
