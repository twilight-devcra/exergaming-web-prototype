# 사칙연산 역산 (`arith`)

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

(?) ± (?) ± (?) = 답 에서 후보 숫자를 골라 빈칸을 모두 채워 식을 완성한다.

- 파일: [js/games/arith.js](../../js/games/arith.js) — 머리 주석에 왜 그렇게 정했는지가 더 있습니다
- 한 게임: 문제 3개 · 꼬리표: number (꼬리표가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 6초 + 5초 × 일의 양 — 일의 양: 빈칸 수
- 능력 그래프: 기억력 0.2 · 주의집중 0.1 · 논리·수리 0.7

## 손잡이

| 손잡이 | 뜻 |
|---|---|
| `blanks` | 빈칸 수. 최대 3개 (4개는 다른 게임보다 지나치게 어려웠다) |
| `n` | 후보 숫자 수 (모두 서로 다른 한 자리 수) |
| `maxSols` | 답이 되는 조합의 최대 개수. 순서만 다른 것은 같은 조합으로 센다. |
| `plus` | 덧셈만 쓴다 (쉬운 단계). 빼는 칸은 '어느 쪽이 커야 하나'까지 따져야 해서 한결 어렵다. |
| `given` | 미리 채워 두는 칸 수 (가장 쉬운 단계). 채워 둔 숫자는 후보에서 빠지므로 n 은 그 숫자까지 센 수다. 빈칸이 하나 남으면 '답 − 채워 둔 수'를 찾기만 하면 된다. |

## 고정값 (모든 레벨 공통)

| 이름 | 값 | 뜻 |
|---|---|---|
| `TRIES` | `120` | 문제 하나를 만들 때 후보 묶음을 다시 뽑아 보는 횟수 (화면이 멈칫하지 않을 만큼만) |

레벨 표의 `–` 는 그 레벨에 값을 두지 않았다는 뜻(손잡이 설명에 적힌 기본값이나 꺼짐), `a~b` 는 그 범위에서 무작위로 고른다는 뜻입니다.
