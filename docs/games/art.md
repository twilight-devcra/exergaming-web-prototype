# 그림 조각 기억하기 (`art`)

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

추상화 한 장을 잠깐 보여 준 뒤 칸이 왼쪽 위부터 대각선 차례로 뒤집힌다. 노란 칸(?)에 있던 조각을 보기에서 고른다.

- 파일: [js/games/art.js](../../js/games/art.js) — 설계 의도는 파일 상단 주석에 더 자세히 있습니다
- 문제 수: 게임당 2개
- 태그: memory (태그가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 3초 + 0.6초 × N, N = 보기 수
- 두뇌 그래프 영역: 기억력 · 시공간 (부분)
- 세부 인지 영역: 즉시 기억 (시각·위치) · 연합 기억 · 시각 변별 (부분) ([점검표](TARGETS.md))

## 난이도 변수

| 변수 | 설명 |
|---|---|
| `cols` | 그림의 가로 칸 수 |
| `rows` | 그림의 세로 칸 수 |
| `show` | 그림을 보여 주는 시간 (ms) |
| `choices` | 보기 수 |
| `pick` | 오답 칸 고르기: far = 묻는 칸과 붙어 있지 않은 칸 · near = 붙어 있는 칸 (대각선 포함) · any = 아무 칸. 모자라면 나머지 칸에서 채운다 |
| `calm` | 차분한 그림: 작은 무늬 없이 큰 모양 몇 개가 이웃한 두 칸에 반씩 걸친다 (낮은 단계) |
| `altered` | 오답 하나는 어느 조각의 작은 무늬 하나를 모양이 다른 짝으로 바꾼 것. 정답에서도 오답 칸에서도 만든다: 늘 정답에서 만들면 '닮은 두 조각 가운데 하나가 정답' 이라 기억 없이 반반으로 맞힌다 |

## 레벨별 값

| Lv | `cols` | `rows` | `show` | `choices` | `pick` | `calm` | `altered` | 메모 |
|---|---|---|---|---|---|---|---|---|
| 1 (쉬움) | 2 | 1 | 5000 | 2 | any | ✓ | – | 차분한 그림: 1×2 → 2×2 → 2×3 |
| 2 (쉬움) | 2 | 2 | 4500 | 2 | far | ✓ | – |  |
| 3 | 3 | 2 | 4000 | 3 | any | ✓ | – |  |
| 4 | 3 | 2 | 4000 | 3 | far | – | – | 같은 2×3 에 보통 그림 (색종이 여러 장, 가로지르는 선, 작은 무늬). 스케치에서 차분한 2×3 다음 바로 3×3 은 너무 가팔랐다 |
| 5 | 3 | 3 | 3500 | 4 | near | – | – |  |
| 6 | 3 | 3 | 3500 | 4 | near | – | ✓ |  |
| 7 | 4 | 3 | 4000 | 4 | near | – | – |  |
| 8 | 4 | 3 | 3500 | 4 | near | – | ✓ |  |

레벨 표의 `–`는 해당 레벨에서 값을 지정하지 않았다는 뜻입니다 (변수 설명의 기본값을 쓰거나 기능이 꺼짐). `a~b`는 그 범위에서 무작위로 정한다는 뜻입니다.
