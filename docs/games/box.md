# 상자 속 과일 세기 (`box`)

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

가운데의 검은 상자로 과일이 들어가고 나온다. 다 끝나면 상자 안에 남은 과일에 대해 묻는다. 한 게임에 순서 하나, 답 하나다.

- 파일: [js/games/box.js](../../js/games/box.js) — 머리 주석에 왜 그렇게 정했는지가 더 있습니다
- 한 게임: 문제 1개 · 꼬리표: memory, number (꼬리표가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 4초 + 1.5초 × 일의 양 — 일의 양: 세어 둬야 할 과일 종류 수 (상자가 둘이면 +1)
- 능력 그래프: 기억력 0.5 · 주의집중 0.3 · 논리·수리 0.2

## 손잡이

| 손잡이 | 뜻 |
|---|---|
| `steps` | 차례 수 |
| `per` | 한 차례에 한 줄로 옮기는 과일 수 [최소, 최대] |
| `kinds` | 과일 종류 수 |
| `mixed` | 한 줄 안에서 다음 과일이 앞 과일과 다른 종류일 확률 (0 이면 한 줄은 늘 같은 과일) |
| `start` | 처음부터 상자 안에 든 과일 수 [최소, 최대]. 상자가 열린 채로 잠깐 보여 준 뒤 닫힌다 (0 이면 빈 상자). 상자가 둘이면 두 상자를 합친 수이고, 상자마다 START_MIN 개 이상 든다. 첫 차례에는 상자를 비우지 않는다 — 비우면 처음 보여 준 과일을 기억할 필요가 없어진다 (예전에는 Lv4 판의 약 4분의 1, Lv8 판의 3분의 1 남짓이 첫 차례에 상자를 비웠다, 2026-11-09) |
| `out` | 한 차례가 빼기(상자 → 밖, 또는 상자 → 상자)일 확률 (기본 OUT. 뺄 것이 없으면 넣는다) |
| `decoy` | 상자 위로 지나가기만 하고 들어가지 않는 과일 수 (주의 흐트리기. 차례와 함께 움직인다. 상자가 하나일 때만) |
| `boxes` | 상자 수. 둘이면 위아래 두 줄에 하나씩 두고 (줄마다 상자 하나일 때와 똑같이 왼쪽에서 들어가 오른쪽으로 나온다) 한쪽 상자에 대해 묻는다. 처음에는 한 줄에 상자 둘을 두고 왼쪽 상자 → 오른쪽 상자로 옮기게 했더니, 나오자마자 다른 상자로 들어가는 과일을 따라가기 벅찼다 (2026-11-02) |
| `q` | 질문 종류: total 모두 몇 개 · kind (그림) 몇 개 · most 가장 많은 과일 · diff (그림)가 (그림)보다 몇 개 더 |
| `opts` | 숫자 보기 수 (기본 4) |

## 고정값 (모든 레벨 공통)

| 이름 | 값 | 뜻 |
|---|---|---|
| `SPEED` | `0.1` | 판 단위/ms. 과일 하나가 칸 끝에서 상자 뒤까지(GAP + FS) 약 1.2초 |
| `PAUSE_MS` | `300` | 한 줄이 다 숨은 뒤 다음 차례까지 |
| `CAP` | `9` | 상자 하나에 들 수 있는 과일 수 (답이 한 자리 수가 되게) |
| `START_MIN` | `2` | 상자가 둘일 때 상자마다 처음 드는 최소 과일 수     // 답이 0 인 문제를 이 정도만 남긴다 (자주 나오면 '0' 을 찍는 것이 수가 된다) |
| `FS` | `46` | 움직이는 과일 크기 (열린 상자 속은 IN_FS) |
| `SP` | `54` | 한 줄에서 과일 사이 거리 (가운데끼리) |
| `GAP` | `76` | 칸 끝과 상자 사이 |
| `H` | `160` | 판 높이. 너비는 상자 수에 따라 |
| `LANE` | `32` | 지나가기만 하는 과일이 다니는 높이 (상자 위) |
| `ROWS` | `{ y: [12, 116], h: 212 }` | 상자가 둘일 때: 줄마다 상자 위쪽 끝, 판 높이 (지나가는 과일 없이) |

레벨 표의 `–` 는 그 레벨에 값을 두지 않았다는 뜻(손잡이 설명에 적힌 기본값이나 꺼짐), `a~b` 는 그 범위에서 무작위로 고른다는 뜻입니다.
