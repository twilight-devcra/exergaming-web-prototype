# 동전 세기 (`coin`)

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

탁자 위에 동전이 흩어져 있고, 몇 개는 다른 동전 위에 겹쳐 얹혀 있다. 세 문제를 차례로 묻는다.

- 파일: [js/games/coin.js](../../js/games/coin.js) — 머리 주석에 왜 그렇게 정했는지가 더 있습니다
- 한 게임: 문제 3개 · 꼬리표: number, search (꼬리표가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 4초 + 0.6초 × 일의 양 — 일의 양: 동전 수 (값을 더하는 Lv4~ 는 동전 수 × 1.3 + 종류 수)
- 능력 그래프: 공간지각 0.4 · 논리·수리 0.4 · 주의집중 0.2

## 손잡이

| 손잡이 | 뜻 |
|---|---|
| `kinds` | 한 문제에 나오는 동전 종류 수 (1 이면 구리 동전만). 종류마다 적어도 하나씩 놓는다 |
| `values` | 배지 값을 뽑는 범위 [최소, 최대]. 한 문제 안에서는 서로 다르다 |
| `n` | 동전 수 [최소, 최대] |
| `overlap` | 동전 하나를 이미 놓인 동전에 걸쳐 놓을 확률 |
| `stack` | 몇 층까지 쌓을 수 있나 (0 = 바닥에만) |
| `minVis` | 동전마다 앞면이 이만큼은 보여야 한다. 가운데 무늬는 늘 다 보이게 둔다 — 무늬가 가려지면 한 닢인지 두 닢인지, 어느 동전인지 알아볼 수 없다 |
| `r` | 동전 반지름 (판 단위) |
| `opts` | 숫자 보기 수 (기본 4) |

## 고정값 (모든 레벨 공통)

| 이름 | 값 | 뜻 |
|---|---|---|
| `VALUE_FROM` | `4` | 이 레벨부터 값을 더한다 |
| `RIM` | `11` | 나무 테두리 두께 |
| `K` | `0.74` | 바닥의 안쪽 방향이 화면에서 줄어드는 비율 (비스듬히 내려다본 정도) |
| `THICK` | `0.18` | 두께 / 반지름 |
| `MAX_TILT` | `0.5` | 가장 많이 기우는 각도 (라디안, 약 29°) |

레벨 표의 `–` 는 그 레벨에 값을 두지 않았다는 뜻(손잡이 설명에 적힌 기본값이나 꺼짐), `a~b` 는 그 범위에서 무작위로 고른다는 뜻입니다.
