# 동전 세기 (`coin`)

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

탁자 위에 동전이 흩어져 있고, 몇 개는 다른 동전 위에 겹쳐 얹혀 있다. 세 문제를 차례로 묻는다.

- 파일: [js/games/coin.js](../../js/games/coin.js) — 설계 의도는 파일 상단 주석에 더 자세히 있습니다
- 문제 수: 게임당 3개
- 태그: number, search (태그가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 4초 + 0.6초 × N, N = 동전 수 (값을 더하는 Lv4~ 는 동전 수 × 1.3 + 종류 수)
- 두뇌 그래프 영역: 계산 · 주의집중 (부분)
- 세부 인지 영역: 계산 · 수 감각 · 선택적 주의 · 도구적 일상생활 과제 ([점검표](TARGETS.md))

## 난이도 변수

| 변수 | 설명 |
|---|---|
| `kinds` | 한 문제에 나오는 동전 종류 수 (1 이면 구리 동전만). 종류마다 적어도 하나씩 놓는다 |
| `values` | 배지 값을 뽑는 범위 [최소, 최대]. 한 문제 안에서는 서로 다르다 |
| `count` | 동전 수 [최소, 최대] |
| `overlap` | 동전 하나를 이미 놓인 동전에 걸쳐 놓을 확률 |
| `stack` | 몇 층까지 쌓을 수 있나 (0 = 바닥에만) |
| `minVisible` | 동전마다 앞면이 이만큼은 보여야 한다. 가운데 무늬는 늘 다 보이게 둔다 — 무늬가 가려지면 한 닢인지 두 닢인지, 어느 동전인지 알아볼 수 없다 |
| `radius` | 동전 반지름 (판 단위) |
| `optionCount` | 숫자 보기 수 (기본 4) |

## 상수 (모든 레벨 공통)

| 이름 | 값 | 설명 |
|---|---|---|
| `VALUE_FROM` | `4` | 이 레벨부터 값을 더한다 |
| `RIM` | `11` | 나무 테두리 두께 |
| `DEPTH_SCALE` | `0.74` | 바닥의 안쪽 방향이 화면에서 줄어드는 비율 (비스듬히 내려다본 정도) |
| `THICK` | `0.18` | 두께 / 반지름 |
| `MAX_TILT` | `0.5` | 가장 많이 기우는 각도 (라디안, 약 29°) |

레벨 표의 `–`는 해당 레벨에서 값을 지정하지 않았다는 뜻입니다 (변수 설명의 기본값을 쓰거나 기능이 꺼짐). `a~b`는 그 범위에서 무작위로 정한다는 뜻입니다.
