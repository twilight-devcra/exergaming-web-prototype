# 두 그림 비교하기 (`compare`)

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

점 격자 위에 굵은 선으로 그린 그림 둘을 나란히 보여 주고, 두 그림이 똑같은지 묻는다 (같아요 / 달라요). 한 게임에 3번.

- 파일: [js/games/compare.js](../../js/games/compare.js) — 머리 주석에 왜 그렇게 정했는지가 더 있습니다
- 한 게임: 문제 3개 · 꼬리표: search (꼬리표가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 2.5초 + 0.35초 × 일의 양 — 일의 양: 왼쪽 그림의 선 수
- 능력 그래프: 주의집중 0.7 · 처리속도 0.3 (처리속도: 문제당 4초 이하면 그대로, 10초 이상이면 ×0.6)

## 손잡이

| 손잡이 | 뜻 |
|---|---|
| `n` | 점 n×n |
| `lines` | 선 수 |
| `changes` | 고를 수 있는 다름. 속 빈 선과 style 은 Lv5 부터 |
| `hollow` | 선 하나가 속 빈 선일 확률 (0 이면 모두 꽉 찬 선) |
| `crowd` | 생김·없어짐·밀림을 선이 붐비는 자리에서 고를 확률 (가장자리에서 바뀌면 윤곽이 달라져 쉽다) |
| `edge` | 꽉 참 ↔ 속 빔을 '속 빈 구간의 끝'(다른 모양의 선과 맞닿은 선)에서 고를 확률. 그러면 구간이 한 칸 늘거나 줄기만 한다 (구간 한가운데를 바꾸면 줄이 둘로 끊겨 보여 쉽다) |

## 레벨별 값

| Lv | `n` | `lines` | `changes` | `hollow` | `crowd` | `edge` | 메모 |
|---|---|---|---|---|---|---|---|
| 1 (쉬움) | 3 | 4 | add, remove | 0 | 0 | 0 | 쉬운 단계: 선이 적고, 선이 생기거나 없어지기만 한다 |
| 2 (쉬움) | 3 | 5 | add, remove | 0 | 0 | 0 |  |
| 3 | 4 | 6 | add, remove, shift | 0 | 0.2 | 0 |  |
| 4 | 4 | 8 | add, remove, shift | 0 | 0.4 | 0 |  |
| 5 | 4 | 8 | add, remove, shift, style | 0.4 | 0.4 | 0.3 | 속 빈 선이 섞이고, 선 모양이 바뀌는 다름이 더해진다 |
| 6 | 6 | 13 | add, remove, shift, style | 0.45 | 0.6 | 0.5 | 점이 촘촘해지고 선이 많아진다 (7×7 까지는 선을 가늘게 그리면 어수선해 보이지 않았다) |
| 7 | 6 | 20 | add, remove, shift, style | 0.5 | 0.7 | 0.7 |  |
| 8 | 7 | 35 | add, remove, shift, style | 0.5 | 0.8 | 0.85 |  |

레벨 표의 `–` 는 그 레벨에 값을 두지 않았다는 뜻(손잡이 설명에 적힌 기본값이나 꺼짐), `a~b` 는 그 범위에서 무작위로 고른다는 뜻입니다.
