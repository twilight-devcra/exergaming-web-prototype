# 우세한 색 찾기 (`count`)

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

n×m 격자에 여러 색을 켜 두고, 그중 가장 많이 켜진 색을 아래 보기에서 고른다.

- 파일: [js/games/count.js](../../js/games/count.js) — 설계 의도는 파일 상단 주석에 더 자세히 있습니다
- 문제 수: 게임당 3개
- 태그: search (태그가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 4초 + 0.42초 × N, N = 켜진 칸 수
- 능력 그래프 가중치: 주의집중 0.5 · 처리속도 0.5 (처리속도: 문제당 생각한 시간이 3초 이하면 그대로, 13초 이상이면 ×0.6)
- 인지 영역: 선택적 주의 · 처리 속도 ([점검표](TARGETS.md))

## 난이도 변수

| 변수 | 설명 |
|---|---|
| `margin` | 1위와 2위의 개수 차이. 차이가 작아지면 눈대중이 안 통하고 실제로 세어야 한다. |
| `colors` | 색 수. 동시에 들고 있어야 하는 집계 수가 늘어난다. |
| `spread` | 비우승 색들이 2위보다 얼마나 적어질 수 있는지. 좁을수록 어느 색도 눈으로 쳐낼 수 없다. |
| `clump` | 같은 색이 서로 붙어 놓일 확률. 뭉쳐 있으면 면적으로 바로 보이고, 흩어지면 하나씩 세야 한다. |
| `grid` | 격자 [행, 열] |
| `cells` | 켜는 칸 수의 상한 (격자를 가득 채우지 않는다) |
