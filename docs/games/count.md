# 우세한 색 찾기 (`count`)

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

n×m 격자에 여러 색을 켜 두고, 그중 가장 많이 켜진 색을 아래 보기에서 고른다.

- 파일: [js/games/count.js](../../js/games/count.js) — 머리 주석에 왜 그렇게 정했는지가 더 있습니다
- 한 게임: 문제 3개 · 꼬리표: search (꼬리표가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 4초 + 0.42초 × 일의 양 — 일의 양: 켜진 칸 수
- 능력 그래프: 주의집중 0.5 · 처리속도 0.5 (처리속도: 문제당 4초 이하면 그대로, 14초 이상이면 ×0.6)

## 손잡이

| 손잡이 | 뜻 |
|---|---|
| `margin` | 1위와 2위의 개수 차이. 차이가 작아지면 눈대중이 안 통하고 실제로 세어야 한다. |
| `colors` | 색 수. 동시에 들고 있어야 하는 집계 수가 늘어난다. |
| `spread` | 비우승 색들이 2위보다 얼마나 적어질 수 있는지. 좁을수록 어느 색도 눈으로 쳐낼 수 없다. |
| `clump` | 같은 색이 서로 붙어 놓일 확률. 뭉쳐 있으면 면적으로 바로 보이고, 흩어지면 하나씩 세야 한다. |
| `grid` | 격자 [행, 열] |
| `cells` | 켜는 칸 수의 상한 (격자를 가득 채우지 않는다) |
