# 가린 숫자 더하기 (`cover`)

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

작은 숫자 여러 개를 판에 늘어놓고 그중 몇 개를 표시가 다른 상자로 덮은 뒤, 두 숫자의 합을 묻는다.

- 파일: [js/games/cover.js](../../js/games/cover.js) — 설계 의도는 파일 상단 주석에 더 자세히 있습니다
- 문제 수: 게임당 3개
- 태그: memory, number (태그가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 5초 + 2.5초 × N, N = 식에 들어간 덮인 숫자 수
- 두뇌 그래프 영역: 계산 · 기억력
- 세부 인지 영역: 즉시 기억 (시각·위치) · 작업 기억 · 계산 · 수 감각 ([점검표](TARGETS.md))

## 난이도 변수

| 변수 | 설명 |
|---|---|
| `count` | 숫자 수 |
| `hidden` | 그중 덮는 수. 외워야 할 (표시, 숫자) 짝이 늘어난다 |
| `both` | 두 숫자가 모두 덮인 것일 확률. 머릿속에서 둘을 다 꺼내 더해야 한다 |
| `optionCount` | 보기 수 |
| `show` | 외우는 시간의 기본 몫(ms). 쉬운 단계만 따로 정하고, 나머지는 SHOW_MS 다 |

## 상수 (모든 레벨 공통)

| 이름 | 값 | 설명 |
|---|---|---|
| `MIN_VALUE` | `2` | 1 은 더해도 거의 생각할 게 없어서 뺀다 |
| `MAX_VALUE` | `9` | 숫자는 모두 서로 다르다 (상자 속 숫자가 겹치면 섞어 기억한 것을 가려낼 수 없다) |
| `SHOW_MS` | `1500` | 외우는 시간 = SHOW_MS + SHOW_PER × 덮을 수 |
| `LID_GAP` | `130` | 상자가 하나씩 닫히는 간격 |
| `FLY_MS` | `520` | css .cv-tok 의 transition 과 같게 |

레벨 표의 `–`는 해당 레벨에서 값을 지정하지 않았다는 뜻입니다 (변수 설명의 기본값을 쓰거나 기능이 꺼짐). `a~b`는 그 범위에서 무작위로 정한다는 뜻입니다.
