# 가린 숫자 더하기 (`cover`)

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

작은 숫자 여러 개를 판에 늘어놓고 그중 몇 개를 표시가 다른 상자로 덮은 뒤, 두 숫자의 합을 묻는다.

- 파일: [js/games/cover.js](../../js/games/cover.js) — 머리 주석에 왜 그렇게 정했는지가 더 있습니다
- 한 게임: 문제 3개 · 꼬리표: memory, number (꼬리표가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 5초 + 2.5초 × 일의 양 — 일의 양: 식에 들어간 덮인 숫자 수
- 능력 그래프: 기억력 0.6 · 주의집중 0.1 · 논리·수리 0.3

## 손잡이

| 손잡이 | 뜻 |
|---|---|
| `n` | 숫자 수 |
| `hidden` | 그중 덮는 수. 외워야 할 (표시, 숫자) 짝이 늘어난다 |
| `both` | 두 숫자가 모두 덮인 것일 확률. 머릿속에서 둘을 다 꺼내 더해야 한다 |
| `opts` | 보기 수 |
| `show` | 외우는 시간의 기본 몫(ms). 쉬운 단계만 따로 정하고, 나머지는 SHOW_MS 다 |

## 고정값 (모든 레벨 공통)

| 이름 | 값 | 뜻 |
|---|---|---|
| `LO` | `2` | 1 은 더해도 거의 생각할 게 없어서 뺀다 |
| `HI` | `9` | 숫자는 모두 서로 다르다 (상자 속 숫자가 겹치면 섞어 기억한 것을 가려낼 수 없다) |
| `SHOW_MS` | `1500` | 외우는 시간 = SHOW_MS + SHOW_PER × 덮을 수 |
| `LID_GAP` | `130` | 상자가 하나씩 닫히는 간격 |
| `FLY_MS` | `520` | css .cv-tok 의 transition 과 같게 |

레벨 표의 `–` 는 그 레벨에 값을 두지 않았다는 뜻(손잡이 설명에 적힌 기본값이나 꺼짐), `a~b` 는 그 범위에서 무작위로 고른다는 뜻입니다.
