# 빈자리 채우기 (`fit`)

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

육각형 타일 판에 한 칸이 비어 있고, 둘레의 타일에서 색깔 선이 그 빈자리로 들어온다.

- 파일: [js/games/fit.js](../../js/games/fit.js) — 설계 의도는 파일 상단 주석에 더 자세히 있습니다
- 문제 수: 게임당 3개
- 태그: shape (태그가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 5초 + 1.5초 × N, N = 보기 조각 수
- 두뇌 그래프 영역: 전두엽 · 시공간
- 세부 인지 영역: 심상 회전 · 시각 구성 ([점검표](TARGETS.md))

## 난이도 변수

| 변수 | 설명 |
|---|---|
| `lines` | 선 수 (1~3). 많을수록 맞춰 볼 끝점이 늘어난다. |
| `cands` | 조각 수. |
| `pick` | 오답을 고르는 방법. far = 정답과 셋 이상의 변에서 다른 것, near = 가장 적게 다른 것, any = 아무거나. |
| `upright` | 조각을 돌려 놓지 않는다 (쉬운 단계). 정답 조각이 빈자리와 같은 방향이라 머릿속으로 돌려 볼 필요가 없다. |

## 레벨별 값

| Lv | `lines` | `cands` | `pick` | `upright` | 메모 |
|---|---|---|---|---|---|
| 1 (쉬움) | 1 | 2 | any | ✓ |  |
| 2 (쉬움) | 1 | 3 | any | ✓ |  |
| 3 | 1 | 3 | any | – |  |
| 4 | 2 | 3 | far | – |  |
| 5 | 2 | 4 | near | – |  |
| 6 | 3 | 4 | far | – |  |
| 7 | 3 | 5 | near | – |  |
| 8 | 3 | 6 | near | – |  |

## 상수 (모든 레벨 공통)

| 이름 | 값 | 설명 |
|---|---|---|
| `R` | `42` | 육각형 중심에서 꼭짓점까지 |
| `GAP` | `7` | 한 변에 선 끝이 둘일 때 변의 한가운데에서 떨어진 거리 |

레벨 표의 `–`는 해당 레벨에서 값을 지정하지 않았다는 뜻입니다 (변수 설명의 기본값을 쓰거나 기능이 꺼짐). `a~b`는 그 범위에서 무작위로 정한다는 뜻입니다.
