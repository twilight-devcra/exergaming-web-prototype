# 빈자리 채우기 (`fit`)

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

육각형 타일 판에 한 칸이 비어 있고, 둘레의 타일에서 색깔 선이 그 빈자리로 들어온다.

- 파일: [js/games/fit.js](../../js/games/fit.js) — 머리 주석에 왜 그렇게 정했는지가 더 있습니다
- 한 게임: 문제 3개 · 꼬리표: shape (꼬리표가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 5초 + 1.5초 × 일의 양 — 일의 양: 보기 조각 수
- 능력 그래프: 공간지각 0.6 · 논리·수리 0.4

## 손잡이

| 손잡이 | 뜻 |
|---|---|
| `lines` | 선 수 (1~3). 많을수록 맞춰 볼 끝점이 늘어난다. |
| `cands` | 조각 수. |
| `pick` | 오답을 고르는 방법. far = 정답과 셋 이상의 변에서 다른 것, near = 가장 적게 다른 것, any = 아무거나. |
| `upright` | 조각을 돌려 놓지 않는다 (쉬운 단계). 정답 조각이 빈자리와 같은 방향이라 머릿속으로 돌려 볼 필요가 없다. |

## 레벨별 값

| Lv | `lines` | `cands` | `pick` | `upright` | 메모 |
|---|---|---|---|---|---|
| 1 (쉬움) | 1 | 2 | any | ✓ |  |
| 2 (쉬움) | 1 | 3 | any | ✓ |  |
| 3 | 1 | 3 | any | – |  |
| 4 | 2 | 3 | far | – |  |
| 5 | 2 | 4 | near | – |  |
| 6 | 3 | 4 | far | – |  |
| 7 | 3 | 5 | near | – |  |
| 8 | 3 | 6 | near | – |  |

## 고정값 (모든 레벨 공통)

| 이름 | 값 | 뜻 |
|---|---|---|
| `R` | `42` | 육각형 중심에서 꼭짓점까지 |
| `GAP` | `7` | 한 변에 선 끝이 둘일 때 변의 한가운데에서 떨어진 거리 |

레벨 표의 `–` 는 그 레벨에 값을 두지 않았다는 뜻(손잡이 설명에 적힌 기본값이나 꺼짐), `a~b` 는 그 범위에서 무작위로 고른다는 뜻입니다.
