# 사다리 타기 (`ladder`)

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

사다리 위의 출발점마다 모양 조각(peg)이 하나씩 있고, 아래 끝 몇 곳에는 모양 구멍이 있다.

- 파일: [js/games/ladder.js](../../js/games/ladder.js) — 설계 의도는 파일 상단 주석에 더 자세히 있습니다
- 문제 수: 게임당 3개
- 태그: trace (태그가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 4초 + 0.7초 × N, N = 구멍에 닿는 길들이 지나는 가로줄 수의 합
- 능력 그래프 가중치: 공간지각 0.3 · 주의집중 0.5 · 처리속도 0.2 (처리속도: 문제당 5초 이하면 그대로, 15초 이상이면 ×0.6)
- 인지 영역: 지속적 주의 · 시각 추적 · 처리 속도 ([점검표](TARGETS.md))

## 난이도 변수

| 변수 | 설명 |
|---|---|
| `lanes` | 세로줄 수 = 보기 수 |
| `rows` | 가로줄을 놓을 수 있는 칸 수 |
| `p` | 칸마다 가로줄을 놓을 확률 |
| `minCross` | 정답 길이 지나는 가로줄의 최소 수 |
| `holes` | 구멍 수 (따라 올라가 봐야 하는 길 수) |
| `kinds` | 조각 모양 수 |
| `slant` | 가로줄 끝 높이의 칸 안 흔들림 (칸 높이 비율). 0 이면 양 끝이 같이 움직여 평평하다 |
| `tricks` | 속임 가로줄 수 |

## 상수 (모든 레벨 공통)

| 이름 | 값 | 설명 |
|---|---|---|
| `JITTER` | `0.28` | 평평한 단계의 칸 안 흔들림 (양 끝이 같이 움직인다) |
| `TRICK` | `[0, 0.2]` | 속임 가로줄 끝이 옆 가로줄 끝을 넘어가는 거리 = GAP + 이 범위 (칸 높이 비율) |
| `DRAW_MS` | `800` | css .lad-trace 의 transition 과 같게 |

레벨 표의 `–`는 해당 레벨에서 값을 지정하지 않았다는 뜻입니다 (변수 설명의 기본값을 쓰거나 기능이 꺼짐). `a~b`는 그 범위에서 무작위로 정한다는 뜻입니다.
