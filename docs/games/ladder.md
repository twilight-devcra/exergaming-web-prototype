# 사다리 타기 (`ladder`)

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

사다리 위의 출발점마다 모양 조각(peg)이 하나씩 있고, 아래 끝 몇 곳에는 모양 구멍이 있다.

- 파일: [js/games/ladder.js](../../js/games/ladder.js) — 머리 주석에 왜 그렇게 정했는지가 더 있습니다
- 한 게임: 문제 3개 · 꼬리표: trace (꼬리표가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 4초 + 0.7초 × 일의 양 — 일의 양: 구멍에 닿는 길들이 지나는 가로줄 수의 합
- 능력 그래프: 공간지각 0.3 · 주의집중 0.5 · 처리속도 0.2 (처리속도: 문제당 5초 이하면 그대로, 15초 이상이면 ×0.6)

## 손잡이

| 손잡이 | 뜻 |
|---|---|
| `lanes` | 세로줄 수 = 보기 수 |
| `rows` | 가로줄을 놓을 수 있는 칸 수 |
| `p` | 칸마다 가로줄을 놓을 확률 |
| `minCross` | 정답 길이 지나는 가로줄의 최소 수 |
| `holes` | 구멍 수 (따라 올라가 봐야 하는 길 수) |
| `kinds` | 조각 모양 수 |
| `slant` | 가로줄 끝 높이의 칸 안 흔들림 (칸 높이 비율). 0 이면 양 끝이 같이 움직여 평평하다 |
| `tricks` | 속임 가로줄 수 |

## 고정값 (모든 레벨 공통)

| 이름 | 값 | 뜻 |
|---|---|---|
| `JITTER` | `0.28` | 평평한 단계의 칸 안 흔들림 (양 끝이 같이 움직인다) |
| `TRICK` | `[0, 0.2]` | 속임 가로줄 끝이 옆 가로줄 끝을 넘어가는 거리 = GAP + 이 범위 (칸 높이 비율) |
| `DRAW_MS` | `800` | css .lad-trace 의 transition 과 같게 |

레벨 표의 `–` 는 그 레벨에 값을 두지 않았다는 뜻(손잡이 설명에 적힌 기본값이나 꺼짐), `a~b` 는 그 범위에서 무작위로 고른다는 뜻입니다.
