# 없던 그림 찾기 (`novel`)

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

판에 그림 몇 개를 잠깐 보여 준 뒤 가림막을 내렸다 올린다. 그사이 처음 보는 그림 하나가 나타난다 — 빈 칸에 더해지거나(add) 있던 그림 하나를 밀어내고 들어간다(replace). 그 없던 그림을 누른다.

- 파일: [js/games/novel.js](../../js/games/novel.js) — 설계 의도는 파일 상단 주석에 더 자세히 있습니다
- 문제 수: 게임당 3개
- 태그: memory (태그가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 5초 + 0.5초 × N, N = 판의 그림 수
- 두뇌 그래프 영역: 기억력
- 세부 인지 영역: 즉시 기억 (시각·위치) ([점검표](TARGETS.md))

## 난이도 변수

| 변수 | 설명 |
|---|---|
| `n` | 처음 그림 수 |
| `grid` | [행, 열] |
| `show` | 처음 판을 보여 주는 시간(ms). 문제 사이에 다시 보여 주는 시간은 그 60% (1.2초 이상) |
| `marks` | 쓰는 무늬 가짓수 (1 = 무늬 없음만) |
| `replace` | 있던 그림을 밀어내고 들어갈 확률 (나머지는 빈 칸에 더해진다). 밀어내면 그림 수가 그대로라 세어 봐서는 모른다 |
| `shuffle` | 가려진 사이 자리를 바꾸는 그림 수 (없거나 0 = 그대로, 'all' = 모두). 지금은 쓰지 않는다 *(현재 어느 레벨에서도 쓰지 않음)* |
| `similar` | 새 그림이 판에 있는 그림과 모양은 같고 무늬만 다를 확률. 그 밖에는 판에 없는 모양으로 고른다 |

| 1 (쉬움) | 2 | 2×3 | 3500 | 1 | 0 | – | 쉬운 단계: 그림이 적고 오래 보여 주며, 새 그림은 늘 빈 칸에 더해진다 |
| 2 (쉬움) | 3 | 2×3 | 3200 | 1 | 0 | – |  |
| 3 | 3 | 3×3 | 2800 | 1 | 0.3 | – |  |
| 4 | 4 | 3×3 | 2600 | 1 | 0.4 | – |  |
| 5 | 4 | 3×3 | 2400 | 1 | 0.5 | – |  |

| 8 | 6 | 3×4 | 1800 | 3 | 0.6 | 0.4 |  |

레벨 표의 `–`는 해당 레벨에서 값을 지정하지 않았다는 뜻입니다 (변수 설명의 기본값을 쓰거나 기능이 꺼짐). `a~b`는 그 범위에서 무작위로 정한다는 뜻입니다.
