# 없던 그림 찾기 (`novel`)

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

판에 그림 몇 개를 잠깐 보여 준 뒤 가림막을 내렸다 올린다. 그사이 처음 보는 그림 하나가 나타난다 — 빈 칸에 더해지거나(add) 있던 그림 하나를 밀어내고 들어간다(replace). 그 없던 그림을 누른다.

- 파일: [js/games/novel.js](../../js/games/novel.js) — 머리 주석에 왜 그렇게 정했는지가 더 있습니다
- 한 게임: 문제 3개 · 꼬리표: memory (꼬리표가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 5초 + 0.5초 × 일의 양 — 일의 양: 판의 그림 수
- 능력 그래프: 기억력 0.6 · 주의집중 0.4

## 손잡이

| 손잡이 | 뜻 |
|---|---|
| `n` | 처음 그림 수 |
| `grid` | [행, 열] |
| `show` | 처음 판을 보여 주는 시간(ms). 문제 사이에 다시 보여 주는 시간은 그 60% (1.2초 이상) |
| `marks` | 쓰는 무늬 가짓수 (1 = 무늬 없음만) |
| `replace` | 있던 그림을 밀어내고 들어갈 확률 (나머지는 빈 칸에 더해진다). 밀어내면 그림 수가 그대로라 세어 봐서는 모른다 |
| `shuffle` | 가려진 사이 자리를 바꾸는 그림 수 (없거나 0 = 그대로, 'all' = 모두). 지금은 쓰지 않는다 *(지금은 어느 레벨에도 두지 않음)* |
| `similar` | 새 그림이 판에 있는 그림과 모양은 같고 무늬만 다를 확률. 그 밖에는 판에 없는 모양으로 고른다 |

레벨 표의 `–` 는 그 레벨에 값을 두지 않았다는 뜻(손잡이 설명에 적힌 기본값이나 꺼짐), `a~b` 는 그 범위에서 무작위로 고른다는 뜻입니다.
