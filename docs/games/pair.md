# 짝 없는 것 찾기 (`pair`)

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

빨랫줄에 양말이 걸려 있다. 모두 똑같은 짝이 있는데 하나만 짝이 없다. 그 양말을 누른다. 한 게임에 3번.

- 파일: [js/games/pair.js](../../js/games/pair.js) — 설계 의도는 파일 상단 주석에 더 자세히 있습니다
- 문제 수: 게임당 3개
- 태그: search (태그가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 3초 + 0.6초 × N, N = 양말 수
- 능력 그래프 가중치: 주의집중 0.5 · 공간지각 0.2 · 처리속도 0.3 (처리속도: 문제당 4초 이하면 그대로, 12초 이상이면 ×0.6)
- 인지 영역: 선택적 주의 · 시각 변별 · 처리 속도 ([점검표](TARGETS.md))

## 난이도 변수

| 변수 | 설명 |
|---|---|
| `n` | 양말 수 (짝 (n-1)/2 쌍 + 하나) |
| `palette` | 쓰는 색 수. 0 이면 양말 종류마다 다른 색 (색만 보고도 짝을 찾을 수 있다) |
| `lure` | 짝 없는 양말이 어느 짝과 한 군데만 다를 확률 (같은 색에 발목이나 무늬 하나만 다르다) |
| `subtle` | 그때 다른 곳이 비슷한 무늬(굵은 줄 ↔ 가는 줄, 하트 ↔ 별 …)다 |
| `flip` | 양말이 저마다 왼쪽·오른쪽을 본다 (한 짝도 서로 반대로 걸릴 수 있다) |

## 상수 (모든 레벨 공통)

| 이름 | 값 | 설명 |
|---|---|---|
| `CELL_W` | `84` | 양말 한 칸 (판 단위) |
| `ROW_H` | `132` | 빨랫줄 한 줄 |

레벨 표의 `–`는 해당 레벨에서 값을 지정하지 않았다는 뜻입니다 (변수 설명의 기본값을 쓰거나 기능이 꺼짐). `a~b`는 그 범위에서 무작위로 정한다는 뜻입니다.
