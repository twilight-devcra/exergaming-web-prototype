# 짝 없는 것 찾기 (`pair`)

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

빨랫줄에 양말이 걸려 있다. 모두 똑같은 짝이 있는데 하나만 짝이 없다. 그 양말을 누른다. 한 게임에 3번.

- 파일: [js/games/pair.js](../../js/games/pair.js) — 머리 주석에 왜 그렇게 정했는지가 더 있습니다
- 한 게임: 문제 3개 · 꼬리표: search (꼬리표가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 3초 + 0.6초 × 일의 양 — 일의 양: 양말 수
- 능력 그래프: 주의집중 0.5 · 공간지각 0.2 · 처리속도 0.3 (처리속도: 문제당 4초 이하면 그대로, 12초 이상이면 ×0.6)

## 손잡이

| 손잡이 | 뜻 |
|---|---|
| `n` | 양말 수 (짝 (n-1)/2 쌍 + 하나) |
| `palette` | 쓰는 색 수. 0 이면 양말 종류마다 다른 색 (색만 보고도 짝을 찾을 수 있다) |
| `lure` | 짝 없는 양말이 어느 짝과 한 군데만 다를 확률 (같은 색에 발목이나 무늬 하나만 다르다) |
| `subtle` | 그때 다른 곳이 비슷한 무늬(굵은 줄 ↔ 가는 줄, 하트 ↔ 별 …)다 |
| `flip` | 양말이 저마다 왼쪽·오른쪽을 본다 (한 짝도 서로 반대로 걸릴 수 있다) |

## 고정값 (모든 레벨 공통)

| 이름 | 값 | 뜻 |
|---|---|---|
| `CELL_W` | `84` | 양말 한 칸 (판 단위) |
| `ROW_H` | `132` | 빨랫줄 한 줄 |

레벨 표의 `–` 는 그 레벨에 값을 두지 않았다는 뜻(손잡이 설명에 적힌 기본값이나 꺼짐), `a~b` 는 그 범위에서 무작위로 고른다는 뜻입니다.
