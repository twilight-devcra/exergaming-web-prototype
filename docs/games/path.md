# 길 따라 그리기 (`path`)

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

격자 위에 경로를 한 칸씩 보여준 뒤, 같은 순서대로 선택하게 한다.

- 파일: [js/games/path.js](../../js/games/path.js) — 머리 주석에 왜 그렇게 정했는지가 더 있습니다
- 한 게임: 문제 1개 · 꼬리표: memory, trace (꼬리표가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 3초 + 1.2초 × 일의 양 — 일의 양: 눌러야 할 칸 수
- 능력 그래프: 기억력 0.5 · 공간지각 0.4 · 주의집중 0.1

## 손잡이

| 손잡이 | 뜻 |
|---|---|
| `grid` | 격자 [행, 열] |
| `len` | 경로의 칸 수 범위 |
| `turns` | 최소 꺾임 횟수 |
| `free` | 꺼져 있으면 왼쪽 열에서 시작해 오른쪽 열에서 끝난다 (진행 방향을 짐작할 수 있다). 켜면 아무 칸에서나 시작해 아무 데서나 끝나고, 되돌아가기도 한다. 이때는 길이 한쪽 구석에 뭉치지 않도록 격자의 거의 전체 폭과 높이에 걸치게 만든다. |
| `touch` | 길이 자기 자신 바로 옆을 지나가도 되는 칸 수. 옆 칸이 다음 칸인지 헷갈리게 된다. 제한 없이 두면 길이 한 덩어리로 뭉쳐 버리므로 몇 칸까지만 허용한다. |
| `step` | 한 칸을 보여주는 시간(ms). 쉬운 단계(Lv1·Lv2)만 따로 정하고, 나머지는 STEP_MS 로 고정이다. |

## 고정값 (모든 레벨 공통)

| 이름 | 값 | 뜻 |
|---|---|---|
| `STEP_MS` | `380` | 경로 한 칸을 보여주는 시간 (쉬운 단계 말고는 난이도와 무관하게 고정) |

레벨 표의 `–` 는 그 레벨에 값을 두지 않았다는 뜻(손잡이 설명에 적힌 기본값이나 꺼짐), `a~b` 는 그 범위에서 무작위로 고른다는 뜻입니다.
