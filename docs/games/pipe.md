# 배관 타기 (`pipe`)

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

위의 출발점마다 모양 조각(peg)이 하나씩 있고, 아래 끝 몇 곳에는 모양 구멍이 있다. 출발점마다 관 하나가 아래 끝 하나로 이어진다. 관을 따라가 같은 모양의 구멍에 쏙 들어가는 조각을 고른다. 그런 조각은 하나뿐이다. 판 하나에 문제 3개.

- 파일: [js/games/pipe.js](../../js/games/pipe.js) — 설계 의도는 파일 상단 주석에 더 자세히 있습니다
- 문제 수: 게임당 3개
- 태그: trace (태그가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 5초 + 0.6초 × N, N = 구멍에 닿는 관들의 길이 (판 단위 100 마다 1)
- 능력 그래프 가중치: 공간지각 0.3 · 주의집중 0.5 · 처리속도 0.2 (처리속도: 문제당 생각한 시간이 3.5초 이하면 그대로, 13.5초 이상이면 ×0.6)
- 인지 영역: 지속적 주의 · 시각 추적 · 처리 속도 ([점검표](TARGETS.md))

## 난이도 변수

| 변수 | 설명 |
|---|---|
| `lanes` | 선 수 = 보기 수 |
| `grid` | 칸 크기 (없으면 GRID 40). 작을수록 관이 가늘고 촘촘하다 |
| `length` | 선마다 지나는 칸 수 [최소, 최대] (칸 40 이면 선 넷까지의 판이 9 × 10 칸, 칸 32 면 12 × 12 칸) |
| `turn` | 한 칸 갈 때마다 꺾을 확률 (낮을수록 길게 곧다) |
| `loops` | 선마다 제 몸을 감아 도는 고리 수 (정수 부분은 늘, 소수 부분은 그 확률로 하나 더) |
| `minCross` | 정답 선이 지나는 엇갈림의 최소 수 (제 몸과 엇갈리는 고리도 센다) |
| `holes` | 구멍 수 (따라 올라가 봐야 하는 선 수) |
| `kinds` | 조각 모양 수 |

## 상수 (모든 레벨 공통)

| 이름 | 값 | 설명 |
|---|---|---|
| `SPEED` | `0.8` | 고른 조각이 선을 따라 가는 빠르기 (SVG 단위/ms). 길이에 따라 0.8 ~ 2.2 초 |
| `GRID` | `40` | 관 사이 간격 (칸 크기). 단계마다 spec.grid 로 바꿀 수 있다 |
| `PIPE` | `0.475` | 관 몸통 굵기 (칸 크기 비율). 나란한 관 사이가 관 굵기쯤 빈다 |
| `EDGE` | `1.8` | 관 테두리 두께 (SVG 단위) |
| `LENGTH_SLACK` | `0.1` | 관 길이가 범위를 벗어나도 되는 정도 (최대 길이 비율) |
| `RIP_UPS` | `12` | 막힌 관 때문에 앞 관을 거두고 다시 내는 횟수 (넘으면 판을 새로) |
| `WALK_TRIES` | `40` | 선 하나의 길을 찾아보는 횟수 (못 찾으면 앞 관을 거두고 다시) |
| `DIRS` | `[[0, 1], [1, 0], [0, -1], [-1, 0]]` | 아래 · 오른쪽 · 위 · 왼쪽 |

레벨 표의 `–`는 해당 레벨에서 값을 지정하지 않았다는 뜻입니다 (변수 설명의 기본값을 쓰거나 기능이 꺼짐). `a~b`는 그 범위에서 무작위로 정한다는 뜻입니다.
