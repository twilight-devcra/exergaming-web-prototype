# 차례대로 외우기 (`recall`)

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

그림(모양과 개수가 있는)이 하나씩 나왔다 사라진다. 다 나온 뒤 그 가운데 한 가지(모양이나 개수)를 나온 차례대로 누른다.

- 파일: [js/games/recall.js](../../js/games/recall.js) — 머리 주석에 왜 그렇게 정했는지가 더 있습니다
- 한 게임: 문제 1개 · 꼬리표: memory (꼬리표가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 4초 + 1.3초 × 일의 양 — 일의 양: 눌러야 할 칸 수
- 능력 그래프: 기억력 0.7 · 주의집중 0.3

## 손잡이

| 손잡이 | 뜻 |
|---|---|
| `n` | 그림 수 (보여 주고 눌러야 할 차례 수) |
| `p` | 바뀌는 성질 수 (1~2). 1 이면 모양이나 개수 가운데 하나만 바뀌고 다른 하나는 모든 그림이 같다 |
| `vals` | 모양 수 (모양을 물을 때의 보기 단추 수). 개수는 늘 하나·둘·셋 세 가지다 |
| `show` | 그림 하나를 보여 주는 시간(ms). 그림 사이에는 GAP_MS 동안 빈 카드가 보인다 |

## 고정값 (모든 레벨 공통)

| 이름 | 값 | 뜻 |
|---|---|---|
| `GAP_MS` | `400` | 그림과 그림 사이에 빈 카드를 보여 주는 시간 |
| `CARD` | `{ w: 300, h: 180 }` | 카드 (판 단위) |

레벨 표의 `–` 는 그 레벨에 값을 두지 않았다는 뜻(손잡이 설명에 적힌 기본값이나 꺼짐), `a~b` 는 그 범위에서 무작위로 고른다는 뜻입니다.
