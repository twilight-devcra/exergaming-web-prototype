# 차례대로 외우기 (`recall`)

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

그림(모양과 개수가 있는)이 하나씩 나왔다 사라진다. 다 나온 뒤 그 가운데 한 가지(모양이나 개수)를 나온 차례대로 누른다.

- 파일: [js/games/recall.js](../../js/games/recall.js) — 설계 의도는 파일 상단 주석에 더 자세히 있습니다
- 문제 수: 게임당 1개
- 태그: memory (태그가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 4초 + 1.3초 × N, N = 눌러야 할 칸 수
- 능력 그래프 가중치: 기억력 0.7 · 주의집중 0.3
- 인지 영역: 순서 기억 · 언어적 기억 ([점검표](TARGETS.md))

## 난이도 변수

| 변수 | 설명 |
|---|---|
| `n` | 그림 수 (보여 주고 눌러야 할 차례 수) |
| `p` | 바뀌는 성질 수 (1~2). 1 이면 모양이나 개수 가운데 하나만 바뀌고 다른 하나는 모든 그림이 같다 |
| `vals` | 모양 수 (모양을 물을 때의 보기 단추 수). 개수는 늘 하나·둘·셋 세 가지다 |
| `show` | 그림 하나를 보여 주는 시간(ms). 그림 사이에는 GAP_MS 동안 빈 카드가 보인다 |

## 레벨별 값

| Lv | `n` | `p` | `vals` | `show` | 메모 |
|---|---|---|---|---|---|
| 1 (쉬움) | 2 | 1 | 3 | 1800 | 쉬운 단계: 모양이나 개수 하나만 바뀐다 |
| 2 (쉬움) | 3 | 1 | 3 | 1800 |  |

| 5 | 5 | 2 | 4 | 1900 |  |

## 상수 (모든 레벨 공통)

| 이름 | 값 | 설명 |
|---|---|---|
| `GAP_MS` | `400` | 그림과 그림 사이에 빈 카드를 보여 주는 시간 |
| `CARD` | `{ w: 300, h: 180 }` | 카드 (판 단위) |

레벨 표의 `–`는 해당 레벨에서 값을 지정하지 않았다는 뜻입니다 (변수 설명의 기본값을 쓰거나 기능이 꺼짐). `a~b`는 그 범위에서 무작위로 정한다는 뜻입니다.
