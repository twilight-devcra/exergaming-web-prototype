# 숨은 순서 찾기 (`seek`)

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

육각형 칸으로 된 육각형 판 어딘가에 왼쪽(좁은 화면에서는 위)에 보이는 그림 순서가 일직선으로 딱 한 번 놓여 있다.

- 파일: [js/games/seek.js](../../js/games/seek.js) — 머리 주석에 왜 그렇게 정했는지가 더 있습니다
- 한 게임: 문제 3개 · 꼬리표: search (꼬리표가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 6초 + 0.25초 × 일의 양 — 일의 양: 판의 칸 수
- 능력 그래프: 공간지각 0.3 · 주의집중 0.4 · 처리속도 0.3 (처리속도: 문제당 5초 이하면 그대로, 18초 이상이면 ×0.6)

## 손잡이

| 손잡이 | 뜻 |
|---|---|
| `radius` | 판 반지름. 칸 수는 1 → 7칸, 2 → 19칸, 3 → 37칸, 4 → 61칸 |
| `len` | 찾을 그림 순서의 길이 |
| `symbols` | 판에 쓰는 그림 가짓수. 칸마다 이 가운데서 무작위로 고른다 |
| `decoys` | 한 칸만 다른 가짜 줄의 수 |
| `slanted` | 첫 문제를 비스듬한 줄에 숨긴다 (쉬운 단계) |

## 고정값 (모든 레벨 공통)

| 이름 | 값 | 뜻 |
|---|---|---|
| `STACK_BELOW` | `560` | 판 자리가 이보다 좁으면 사슬을 판 위에 둔다 (px) |
| `DIRS` | `[[1, 0], [0, 1], [-1, 1], [-1, 0], [0, -1], [1, -1]]` | 축 좌표 (q, r)의 여섯 방향 |
| `UNIT` | `50` | SVG 안에서 육각형 한 칸의 반지름 |

레벨 표의 `–` 는 그 레벨에 값을 두지 않았다는 뜻(손잡이 설명에 적힌 기본값이나 꺼짐), `a~b` 는 그 범위에서 무작위로 고른다는 뜻입니다.
