# 숨은 순서 찾기 (`seek`)

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

육각형 칸으로 된 육각형 판 어딘가에 왼쪽(좁은 화면에서는 위)에 보이는 그림 순서가 일직선으로 딱 한 번 놓여 있다.

- 파일: [js/games/seek.js](../../js/games/seek.js) — 설계 의도는 파일 상단 주석에 더 자세히 있습니다
- 문제 수: 게임당 3개
- 태그: search (태그가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 6초 + 0.25초 × N, N = 판의 칸 수
- 두뇌 그래프 영역: 시공간
- 세부 인지 영역: 선택적 주의 · 처리 속도 ([점검표](TARGETS.md))

## 난이도 변수

| 변수 | 설명 |
|---|---|
| `radius` | 판 반지름. 칸 수는 1 → 7칸, 2 → 19칸, 3 → 37칸, 4 → 61칸 |
| `sequenceLength` | 찾을 그림 순서의 길이 |
| `symbolCount` | 판에 쓰는 그림 가짓수. 칸마다 이 가운데서 무작위로 고른다 |
| `decoys` | 한 칸만 다른 가짜 줄의 수 |
| `slanted` | 첫 문제를 비스듬한 줄에 숨긴다 (쉬운 단계) |

## 상수 (모든 레벨 공통)

| 이름 | 값 | 설명 |
|---|---|---|
| `STACK_BELOW` | `560` | 판 자리가 이보다 좁으면 사슬을 판 위에 둔다 (px) |
| `DIRECTIONS` | `[[1, 0], [0, 1], [-1, 1], [-1, 0], [0, -1], [1, -1]]` | 축 좌표 (column, row)의 여섯 방향 |
| `UNIT` | `50` | SVG 안에서 육각형 한 칸의 반지름 |

레벨 표의 `–`는 해당 레벨에서 값을 지정하지 않았다는 뜻입니다 (변수 설명의 기본값을 쓰거나 기능이 꺼짐). `a~b`는 그 범위에서 무작위로 정한다는 뜻입니다.
