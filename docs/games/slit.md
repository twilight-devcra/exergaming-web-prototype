# 물고기 엿보기 (`slit`)

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

남색 띠의 좁은 틈 뒤로 물고기 한 마리가 오른쪽에서 왼쪽으로 헤엄쳐 지나간다. 틈으로 보인 조각을 이어 보고 아래 보기에서 똑같은 물고기를 고른다.

- 파일: [js/games/slit.js](../../js/games/slit.js) — 설계 의도는 파일 상단 주석에 더 자세히 있습니다
- 문제 수: 게임당 2개
- 태그: track (태그가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 0초 + 1초 × N, N = 초 (게임이 레벨의 볼 횟수로 셈한다)
- 두뇌 그래프 영역: 시공간 · 주의집중 (부분)
- 세부 인지 영역: 시각 구성 · 지속적 주의 · 시각 추적 (부분) · 시각 변별 (부분) ([점검표](TARGETS.md))

## 난이도 변수

| 변수 | 설명 |
|---|---|
| `complexity` | 물고기 복잡도 (1~3). 1: 몸 · 꼬리 · 등지느러미 · 세로 줄 무늬 2: 몸과 무늬가 늘고 배지느러미 · 무늬 개수 · 3: 눈 · 입 · 아가미 선까지 |
| `change` | 보기끼리 다른 곳: big 부분의 종류 (꼬리 갈래 → 둥긂) · small 개수와 작은 부분 (줄 2 → 3, 큰 눈) · mixed 둘 다 |
| `slit` | 틈 너비 (물고기 너비에 대한 몫) |
| `pass` | 물고기가 틈을 다 지나가는 시간 (초) |
| `choices` | 보기 수 |
| `looks` | 제한 시간 안에 물고기를 볼 수 있는 횟수 (처음 지나가는 것 포함). 제한 시간은 이것으로 셈한다 (timeLimit) |
