# 심볼 위치 외우기 (`symbol`)

> 이 폴더의 문서는 `node tools/manual.js` 가 게임 코드에서 만듭니다. 직접 고치지 마세요.
> 바꾸려면 게임 파일(`js/games/*.js`)의 머리 주석·`levels`·고정값 주석을 고친 뒤 스크립트를 다시 돌립니다.

2x4 판의 몇 칸에 서로 다른 심볼을 잠깐 보여준 뒤, 위쪽 칸에 뜬 심볼이 어디 있었는지 3번 맞힌다 (심볼이 둘뿐인 가장 쉬운 단계는 2번).

- 파일: [js/games/symbol.js](../../js/games/symbol.js) — 머리 주석에 왜 그렇게 정했는지가 더 있습니다
- 한 게임: 문제 3개 · 꼬리표: memory (꼬리표가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 6초 + 0초 × 일의 양 — 일의 양: 1
- 능력 그래프: 기억력 0.6 · 공간지각 0.3 · 주의집중 0.1

## 손잡이

| 손잡이 | 뜻 |
|---|---|
| `n` | 보여 주는 심볼 수 (판 8칸 가운데 몇 칸에 놓나) |
| `show` | 심볼을 보여 주는 시간(ms). 쉬운 단계(Lv1·Lv2)만 따로 정하고, 나머지는 SHOW_MS 로 고정이다 |

## 레벨별 값

| Lv | `n` | `show` | 메모 |
|---|---|---|---|
| 1 (쉬움) | 2 | 4500 |  |
| 2 (쉬움) | 3 | 4500 |  |
| 3 | 3 | – |  |
| 4 | 4 | – |  |
| 5 | 5 | – |  |
| 6 | 6 | – |  |
| 7 | 7 | – |  |
| 8 | 8 | – |  |

레벨 표의 `–` 는 그 레벨에 값을 두지 않았다는 뜻(손잡이 설명에 적힌 기본값이나 꺼짐), `a~b` 는 그 범위에서 무작위로 고른다는 뜻입니다.
