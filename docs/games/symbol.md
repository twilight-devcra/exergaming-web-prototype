# 심볼 위치 외우기 (`symbol`)

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

2x4 판의 몇 칸에 서로 다른 심볼을 잠깐 보여준 뒤, 위쪽 칸에 뜬 심볼이 어디 있었는지 3번 맞힌다 (심볼이 둘뿐인 가장 쉬운 단계는 2번).

- 파일: [js/games/symbol.js](../../js/games/symbol.js) — 설계 의도는 파일 상단 주석에 더 자세히 있습니다
- 문제 수: 게임당 3개
- 태그: memory (태그가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 6초 + 0초 × N, N = 1
- 두뇌 그래프 영역: 기억력
- 세부 인지 영역: 즉시 기억 (시각·위치) · 연합 기억 (부분) ([점검표](TARGETS.md))

## 난이도 변수

| 변수 | 설명 |
|---|---|
| `n` | 보여 주는 심볼 수 (판 8칸 가운데 몇 칸에 놓나) |
| `show` | 심볼을 보여 주는 시간(ms). 쉬운 단계(Lv1·Lv2)만 따로 정하고, 나머지는 SHOW_MS 로 고정이다 |

## 레벨별 값

| Lv | `n` | `show` | 메모 |
|---|---|---|---|
| 1 (쉬움) | 2 | 4500 |  |
| 2 (쉬움) | 3 | 4500 |  |
| 3 | 3 | – |  |
| 4 | 4 | – |  |
| 5 | 5 | – |  |
| 6 | 6 | – |  |
| 7 | 7 | – |  |
| 8 | 8 | – |  |

레벨 표의 `–`는 해당 레벨에서 값을 지정하지 않았다는 뜻입니다 (변수 설명의 기본값을 쓰거나 기능이 꺼짐). `a~b`는 그 범위에서 무작위로 정한다는 뜻입니다.
