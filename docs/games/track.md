# 공 따라가기 (`track`)

> 이 문서는 `node tools/manual.js`가 게임 코드에서 자동으로 생성합니다. 직접 수정하지 마세요.
> 내용을 바꾸려면 게임 파일(`js/games/*.js`)의 상단 주석, `levels`, 상수 주석을 수정한 뒤 스크립트를 다시 실행하세요.

똑같은 공 여러 개 가운데 몇 개에 ★ 이 잠깐 떴다가 사라지고, 공들이 이리저리 움직인 뒤 멈춘다. ★ 이 있던 공을 고른다.

- 파일: [js/games/track.js](../../js/games/track.js) — 설계 의도는 파일 상단 주석에 더 자세히 있습니다
- 문제 수: 게임당 1개
- 태그: track (태그가 겹치는 게임은 연달아 나오지 않음)
- 제한 시간: 4초 + 1.5초 × N, N = 고를 공 수
- 능력 그래프 가중치: 주의집중 0.6 · 공간지각 0.3 · 처리속도 0.1
- 인지 영역: 지속적 주의 · 시각 추적 · 분할 주의 · 이중 과제 (부분) ([점검표](TARGETS.md))

## 난이도 변수

| 변수 | 설명 |
|---|---|
| `n` | 공 수 |
| `t` | 고를 공(★) 수 |
| `speed` | 빠르기 (판 단위/초. 판은 가로 160 · 세로 100) |
| `move` | 움직이는 시간(ms) |
| `pass` | 공끼리 겹쳐 지나간다 (아니면 서로 튕긴다) |
| `cue` | ★ 을 보여 주는 시간(ms) |
| `wander` | 공이 곧게만 가지 않고 휘어 가는 정도 (초당 최대 회전 각도). 가던 방향으로 짐작해서는 못 찾게 한다 |

## 상수 (모든 레벨 공통)

| 이름 | 값 | 설명 |
|---|---|---|
| `R` | `7` | 공 반지름 |
| `DT` | `1 / 120` | 미리 계산하는 장면 간격(초) |
| `ACCEL` | `0.5` | 출발할 때 제 빠르기까지 붙는 시간(초). 처음부터 제 빠르기로 튀어 나가면 ★ 공을 놓치기 쉽다 |

레벨 표의 `–`는 해당 레벨에서 값을 지정하지 않았다는 뜻입니다 (변수 설명의 기본값을 쓰거나 기능이 꺼짐). `a~b`는 그 범위에서 무작위로 정한다는 뜻입니다.
