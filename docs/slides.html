일정한 페달링 유도

숫자 없이, 공 하나로 속도를 맞춥니다

목표 속도 유지 · 초록 구역 안 → 초당 +10점
너무 느림 · 공이 왼쪽으로 밀려나고 구역이 붉게 → 점수 감소
목표 속도 상승 · 지면이 오르막으로 기울어짐

공의 위치 = 속도

목표보다 느리면 왼쪽, 빠르면 오른쪽으로 움직입니다. 구역 밖에서는 ››› 표시로 방향을 알려줍니다.

목표 속도 변화

40초마다 평지 → 오르막(+12%) → 평지 → 내리막(−12%). 지면 각도와 비트 템포가 12초에 걸쳐 부드럽게 바뀝니다.

리듬으로 유도

기준 속도에 맞춘 비트 음악(킥 = A, 스네어 = D)과 좌우 가장자리 깜빡임. 소음이 커도 시각 신호로 맞출 수 있습니다.

인지 게임 1

길 따라 그리기

경로가 왼쪽 열에서 오른쪽 열까지 한 칸씩 켜지며 연결선으로 이어집니다. 이후 모두 꺼지고 첫 칸만 남습니다.

보여준 경로를 기억했다가 같은 순서로 칸을 눌러 길을 완성합니다.

난이도
격자 크기 3×4 → 6×9
고정 요소
경로 한 칸을 보여주는 시간 (0.38초)
직관성
떨어진 네모 배열 + 칸 사이 연결선으로 ‘길’을 표현, 첫 칸은 미리 켜 둠
점수
맞힌 칸마다 60점을 나눠 지급 + 완성 보너스 40점, 난이도 배율 적용
오답
틀린 칸을 누르면 즉시 종료, 남은 정답 경로를 흐리게 보여줌

인지 게임 2

심볼 위치 외우기

① ‘외우세요!’ 안내
② 심볼을 3.2초 동안 공개
③ 위 칸의 심볼이 어디 있었는지 선택
④ 고른 칸은 닫히고 ✓ / ✕ 표시

2×4 판에 잠깐 나타난 심볼의 위치를 기억해, 위쪽 칸에 뜬 심볼이 있던 곳을 3번 맞힙니다.

난이도
심볼 수 3개 → 8개
고정 요소
노출 시간 3.2초, 8종 심볼은 모양과 색이 모두 다름
직관성
질문 단계에서 ‘어디 있었나요?’ 문구, 한 번 고른 칸은 다시 못 고름
점수
3문항을 모두 끝낸 뒤 맞힌 개수만큼 지급 (개당 100/3점 × 배율)

사칙연산 역산

채울 칸은 강조 테두리, 고른 숫자는 비활성
정답 시 초록색, 진행 점으로 3문제 표시

(?) ± (?) = 답 형태의 식에서, 아래 후보 숫자 중 두 개를 골라 식을 완성합니다.

난이도
후보 4개·한 자리 수 → 후보 8개·두 자리 수
생성 규칙

오답
답이 될 수 없는 숫자를 고르는 즉시 오답, 정답 식을 보여줌
점수
맞든 틀리든 3문제, 맞힌 식마다 100/3점 × 배율

꾸준한 운동과 정확한 풀이를 모두 보상합니다

운동 점수
10점/ 1초 최대
  • 허용 구역(±12%) 안이면 만점, 벗어난 만큼 줄고 ±45%에서 0점
  • 라운드 길이가 고정이라 만점도 고정: 3분이면 1,800점
  • 인지 게임을 얼마나 빨리 풀든 운동 만점은 같음
인지 게임 점수
100점× 난이도 배율 / 1게임 만점
  • 세 게임 모두 같은 만점, 레벨당 배율 +0.2
  • 오답은 0점이라 대충 빨리보다 정확하게가 유리
  • 레벨은 순환 횟수로만 오르고 배율 증가폭을 낮게 잡아, 쉬운 게임을 일부러 빨리 틀려도 이득이 없음
총점 = 운동 점수 + 인지 게임 점수  ·  결과 화면에서 두 점수를 따로 보여줍니다
